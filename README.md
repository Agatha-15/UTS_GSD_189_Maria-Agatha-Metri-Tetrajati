## Menjalankan ulang
1. Unduh dataset dari Kaggle (retailrocket/ecommerce-dataset), taruh `events.csv` di folder `data/`.
2. `pip install -r requirements.txt`
3. Jalankan Neo4j 5.x, lalu set `export NEO4J_PASSWORD="password-neo4j-kamu"`.
4. Jalankan notebook dari atas ke bawah.
